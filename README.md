# 小智 · 手机里的私人 AI 助手

> **会聊、会看、会记事、会动手操作手机，断网也能用。**

小智（`com.xiaozhi.assistant`）是一款运行在 Android 手机上的个人 AI 助手。它把「聊天、识屏、记忆、待办、系统操控」合进一个 App：说一句话就能设提醒、打开 App、读屏幕、管理记忆，复杂的事还能拆成多步替你一步步做完。

- 适配：Android 8.0+（minSdk 26），Android 12+ 体验最佳（targetSdk 34）
- 体积：约 260 KB · 无广告 · 无第三方统计 SDK · 不依赖应用商店
- 当前构建：v3.3.0（versionCode 33）
- 开发者：i泓（个人项目，本地自签名分发）

---

## 亮点

- 🗣 **双模对话**：本地规则离线可用，配置 API 后升级为联网 AI，自动切换
- 👀 **识屏**：读聊天、读题目、读菜单、比价、翻译，还能分析对方情绪与好感度
- 🖐 **手机操控**：开应用、129 款应用内搜索跳转、16 项系统设置直达、微信扫码/付款码一键跳转
- 📝 **自然语言记事**：「记住我下周交房租」「明天 9 点提醒我交周报」直接生效
- 🎈 **悬浮球**：不离开当前应用就能对话、翻译、识屏、全屏记忆
- 🔒 **数据本地**：记忆、待办、截图都存在手机里，只有你自己配置的 API 会参与联网

## 工作模式

| 模式 | 条件 | 能力 |
| --- | --- | --- |
| 本地模式 | 默认，无需配置 | 待办/提醒、闹钟、跳系统设置、开应用、截屏、识屏、返回/桌面 |
| 联网 AI 模式 | 我的 → 设置 → AI 服务，填一个 OpenAI 兼容的 API 地址与模型 | 完整对话、多步任务拆解执行、AI 识图/识屏、翻译、起标题、发现页洞察 |

复杂任务会自动拆成多步、逐个执行并汇报进度；遇到需要你决定的事（没装应用、缺权限、信息不足），会给出 2–4 个可直接点击的选项，不用自己拆解指令。

## 核心功能

### 对话
- 长按说话、松开识别；语音引擎可选系统或 AI
- 会话自动起标题、可导出；「猜你想说」给出可直接点的下一步
- 设置按功能分 6 组，一键恢复默认

### 悬浮球
- 单击 / 双击 / 长按三种手势，面板按功能分组，3/5 排折叠
- 在悬浮窗内直接对话、翻译、识屏、全屏记忆，不跳转 App
- v3.0 新增「回复」「情感」识屏：一键生成聊天回复、分析对方情绪与好感度
- 4 种窗型风格、贴边半隐藏、防误触

### 识屏
- 录屏权限与无障碍双通道，每次识屏先确认，已开无障碍则直接识屏
- 六类动作：读屏总结、解题、购物比价、看图识图、全屏记忆、翻译
- 识图/识屏结果自动接入 AI，未配置 API 时回落到本地规则

### 记事（记忆 + 待办）
- 自然语言「记住……」即刻入库，支持分类、排序、AI 检索与压缩总结
- 待办支持每天/每周重复，逾期待办自动顺延，可一键导入系统日程
- 全屏记忆：识屏截图作为原图存档

### 发现
- 屏幕使用时长统计（系统 + 小智）、AI 行为分析、洞察自动分析
- 计步与睡眠式发现页，Top 应用一目了然

### 系统操控
- 129 款应用内搜索跳转；未装应用先询问再引导下载
- 16 项系统设置直达（Wi-Fi、亮度、音量、蓝牙等）
- 定时提醒、开机自启恢复待办、微信扫码/付款码跳转

## 隐私与数据

- 记忆、待办、对话、截图全部保存在本机「小智」目录，不上传服务器
- 联网只发生在你主动发起的聊天、AI 识图、AI 检索与分析，请求走你自己填的 API
- 不申请无关权限；敏感操作（付款码、扫码等）默认二次确认

## 安装与上手

1. **安装**：直接安装 APK。自签名包与线上版互斥，装前先卸载旧版
2. **开权限**：
   - 悬浮窗（悬浮球与对话窗口）
   - 无障碍「小智 · 手机操控」（识屏、操控手机必需）
   - 录屏（识屏用）
   - 麦克风（语音用）
3. **配 AI（可选）**：我的 → 设置 → AI 服务，填入 OpenAI 兼容地址与模型；不配也能用本地模式

## 常见问题

**Q：不配 API 能用吗？**
能。本地模式下可处理待办、提醒、开应用、跳设置、截屏、识屏等日常操作；配 API 后解锁完整 AI 对话与多步任务。

**Q：识屏会乱读吗？**
每次识屏前都会先确认（或已开无障碍直接执行）；读到的内容你可以点开原图核对，也可以不再允许。

**Q：会不会偷偷联网？**
不会。只有你主动发起聊天、AI 识图/检索时才联网，且走你自己配置的 API。

**Q：怎么升级？**
单机自签分发包不自动更新，装新版本 APK 覆盖即可（先备份记忆）。
