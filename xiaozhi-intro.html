FEATURES

六件顺手小事，它都会

聊天、识屏、记忆、待办、发现、操控手机——收进一个 App。

🗣

双模对话

本地规则离线可用，配置 API 后升级联网 AI，长按说话松开识别，全自动切换。

👀

识屏

读聊天、读题目、读菜单、比价、翻译；v3.0 还能分析对方情绪与好感度。

🖐

手机操控

开应用、129 款应用内搜索跳转、16 项系统设置直达，微信扫码/付款码一键跳转。

📝

自然语言记事

「记住我下周交房租」「明天 9 点提醒我交周报」直接生效，支持每天/每周重复。

🎈

悬浮球

不离开当前应用就能对话、翻译、识屏、全屏记忆；三种手势、4 种窗型。

🔒

数据本地

记忆、待办、截图都存在手机里。只有你主动发起的联网请求才走你自己的 API。

MODES

两种模式，自动切换

没网不尴尬，有网更聪明。

离线 · 默认

本地模式

  • 待办 / 提醒 / 闹钟
  • 打开应用、跳系统设置
  • 截屏、识屏、返回 / 桌面
  • 无需任何配置
在线 · 配置后启用

联网 AI 模式

  • 完整对话与多步任务拆解
  • AI 识图 / 识屏 / 翻译 / 起标题
  • 发现页智能洞察分析
  • OpenAI 兼容 API，自己填地址与模型
QUICK START

三步用起来

装 APK

直接安装。
自签名包与线上版互斥，装前先卸载旧版。

开权限

悬浮窗 + 无障碍「小智 · 手机操控」+ 录屏 + 麦克风。
识屏、操控手机都需要它们。

配 AI（可选）

我的 → 设置 → AI 服务，
填 OpenAI 兼容地址与模型；
不配也能用本地模式。
